# Data Acquisition Plan

## Current Status

The final dataset has not yet been selected. Dataset selection will be based on accessibility, suitability for studying missing clinical data, availability of relevant prediction outcomes, and advisor feedback.

## Selection Criteria

Candidate datasets should:

* Contain clinical or EHR-related information.
* Include meaningful patterns of missing data.
* Provide sufficient observations and features for machine learning experiments.
* Permit academic/research use.
* Support a clearly defined prediction task.
* Allow analysis without exposing private or identifiable patient information.

## Data Privacy

Raw datasets will not be committed to the GitHub repository. Dataset files will be excluded through `.gitignore` where appropriate.

Only documentation, code, and non-sensitive derived results will be maintained in the repository.
